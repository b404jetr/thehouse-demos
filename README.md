# The House of Avrbhv — Concierge Demo

An interactive, frontend-only demonstration of the Concierge workspace. Seed/demo data is fictional. This is not connected to Supabase, Clerk, email, payments, or a live backend.

## Run
1. Install Node.js (LTS recommended).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the URL Vite prints (usually http://localhost:5173).

The demo supports navigation, adding invitation entries, browsing seeded Artists and Patrons, creating demo commission records, and viewing a commission pipeline. Actions persist only in the current browser session (localStorage).
